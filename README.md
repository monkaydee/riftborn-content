# RIFTBORN content

Set data and card art that Slab Tycoon downloads at runtime
(`manifest.json`, `sets/<id>.json`, `art/<id>.zip`).

Generated by `tools/pack_content.py` in the game repo; don't edit by hand.
Re-run it and replace these files to publish new sets or art.

## reference/

Reference images for the art prompts: `style_*.jpg` style sheets and every
finished Base Rift card (`base_rift/<id>.webp`). Download this folder into
your art folder as `_reference/` (see VARIANT_PROMPTS.md in the game repo).
